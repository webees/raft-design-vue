## 上游

- 仓库：https://github.com/botiverse/raft-design
- 许可证：MIT（https://github.com/botiverse/raft-design/blob/main/LICENSE）
- 内置的设计文档、设计令牌、主题、图标 recipe 与 CSS 基础层源自上游仓库。
- 确切的上游提交记录在 `tooling/upstream/upstream.lock.json`。

MIT 许可证覆盖源代码与文档，不授予 Raft 商标、logo、插画、Agent 角色精灵、
reaction 素材或其它品牌资产的权利。因此本仓库不附带 Raft 品牌素材；依赖
上游精灵的主题装饰在不含素材的情况下生成。

## 第三方作品

- 上游组件原语为 Base UI（React）；本移植使用 Reka UI（Vue）提供等价
