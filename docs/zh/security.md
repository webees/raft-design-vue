# 安全策略

[English](../../SECURITY.md) | **简体中文**

## 支持版本

项目处于 1.0 之前。安全修复进入 `main` 并在下一个补丁版本发布，仅最新的
已发布次版本获得修复。

## 上报漏洞

不要开公开 issue，请使用 GitHub 私有漏洞上报：

1. 打开仓库 **Security** 标签页。
2. 选择 **Report a vulnerability**。
3. 提供受影响版本、最小复现、影响与建议缓解方案。

我们会在 72 小时内确认。修复与披露日期将与您协调；在公开细节前请给予
合理的修复窗口。

## 范围

本仓库是设计系统的 Vue 移植。上游 Raft 代码的漏洞也应同时上报上游项目。
依赖漏洞由 Dependabot 与 `bun audit` 处理。
